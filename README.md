# Programación para la investigación

Libro abierto e interactivo para doctorandos y personal investigador: flujo de trabajo reproducible con Git, Python para investigar, procesos ETL, consumo de API académicas (OpenAlex, Crossref), creación de paquetes de R y Python, y servidores MCP para conectar herramientas de investigación con asistentes de IA.

**Léelo en:** <https://pablosancheznunez.com/programacion-investigacion/> (también en PDF y EPUB).

- Ejercicios autocorregidos de **Python** (Pyodide) y **R** (webR) que se ejecutan en el navegador, con los motores alojados en el propio sitio.
- Laboratorios: generador de `.gitignore`, probador de expresiones regulares, consulta en directo a OpenAlex y servidor MCP simulado con llamada real a Crossref.
- Autoevaluación (también en Moodle XML), retos evaluables, modo claro y oscuro, WCAG 2.1 AA.
